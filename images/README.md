# Aset Visual, Diagram, dan Grafik Evaluasi

Direktori `images/` digunakan untuk menyimpan aset grafis arsitektur, diagram alur, dan keluaran grafik visualisasi performa.

## Pembagian Subdirektori:
* **`export/`**:
  * Diagram alur arsitektur sistem JAGA-KODE.
  * Rancangan mock-up antarmuka dan visualisasi radar Explanation Card untuk materi presentasi Healthkathon.
* **`output/`**:
  * Kurva hasil evaluasi model (*Precision-Recall Curve / PR-AUC*).
  * Grafik perbandingan metrik Precision@K pada variasi ambang batas K.
  * Matriks konfusi (*Confusion Matrix*) dan visualisasi klaster *Peer Grouping*.
