# Laporan & Ringkasan Hasil Evaluasi (Reports)

Direktori `reports/` dirancang untuk mengarsipkan berkas laporan formal, ringkasan eksekutif riset, serta angka metrik final untuk keperluan presentasi dan pengujian sistem JAGA-KODE.

## Pembagian Subdirektori:
* **`figures/`**:
  * Gambar-gambar grafik beresolusi tinggi yang siap disematkan ke dalam laporan akhir (draf proposal slide / paper ilmiah).
* **`metrics/`**:
  * Tabel ringkasan performa numerik (*Precision@K*, *Review Yield*, *PR-AUC*, dan waktu pemrosesan) dalam format CSV/Markdown/JSON hasil pengujian eksperimen.
